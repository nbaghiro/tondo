# Tondo docs

Tondo gives a person or a team one address, such as `tondo.page/maya`, for a page of links with a designed look. A tondo is a circular painting, and that shape is the starting point for the brand. The repo is set up, and the product code is still a thin first version.

| File | What it covers |
|---|---|
| [roadmap.md](roadmap.md) | Order of work, the first release's blocks and open decisions |
| `.scratchpad/editor/index.html` | Editor experiment. Open the file in a browser. Its page styles are copied from the marketing build |
| [features.md](features.md) | Everything Tondo should eventually support, and the decisions that protects |
| [competitors.md](competitors.md) | Analysis of Liinks, Linktree, Beacons, Stan, Later and Shorby |
| [block-system.md](block-system.md) | The full proposed list of blocks, variants, controls and integrations |
| [builder-port.md](builder-port.md) | The final plan for the full builder: every block's layouts and fields, what was cut, and the order of work |
| [data-model.md](data-model.md) | How pages and blocks get saved, and why Postgres with JSONB fits |
| [inspector-design.md](inspector-design.md) | Every block's layouts and inspector fields, with the demo at `.scratchpad/inspector/index.html` |
| [how-it-works.md](how-it-works.md) | Proposed product surfaces, data model, rendering, art and open decisions |
| [deploy.md](deploy.md) | How to set up Neon, Neon Auth and Render, and what is needed before it works |
| [repo-structure.md](repo-structure.md) | Proposed folder layout, package boundaries and local ports |
| [design-language.md](design-language.md) | Competitor comparison, brand decisions, page looks and blocks |

| [marketing/examples.html](marketing/examples.html) | All 50 example pages, grouped by type, showing what the finished product should be able to do |
| [design-brief.md](design-brief.md) | A brief to hand to a separate design agent |
| [design-languages/index.html](design-languages/index.html) | Earlier studies and Wash variations |

Everything here is a proposal until it has been built. The prices, features and people on the design pages are placeholders.
